# `lib/components/ui`

[← lib/components](../README.md)

Generic, app-agnostic UI primitives — buttons, form fields, pickers,
modals — used across every feature area. None of these know about
tournaments, timers, or games specifically.

## Files

| File | Purpose |
|---|---|
| [BackButton.md](BackButton.md) | Themed back-navigation button |
| [BottomSheet.md](BottomSheet.md) | Modal bottom sheet shell (header/scroll body/footer) |
| [ChipGroup.md](ChipGroup.md) | Selectable/cyclable chip group |
| [Combobox.md](Combobox.md) | Dropdown select with a "live" indicator dot |
| [Dialog.md](Dialog.md) | App-wide confirm/alert dialog, exposed via `useDialog()` |
| [DirectionPicker.md](DirectionPicker.md) | Two-button up/down direction toggle |
| [EmptyState.md](EmptyState.md) | Centered placeholder message |

| [InfoButton.md](InfoButton.md) | Small (i) button opening an info dialog |
| [Markdown.md](Markdown.md) | Themed Markdown renderer |
| [PieChart.md](PieChart.md) | Minimal SVG pie chart |
| [PlayerSelectionCard.md](PlayerSelectionCard.md) | Card showing/changing the current player's team+name |
| [ResizableTextInput.md](ResizableTextInput.md) | Multiline text input with a drag-to-resize handle |
| [SearchInput.md](SearchInput.md) | Search box with a clear button |
