# `lib/components/statistics`

[← lib/components](../README.md)

Presentational pieces for the admin statistics tab
([`StatisticsTab`](../admin/StatisticsTab.md)), which computes the actual
numbers via [`lib/utils/statistics.ts`](../../utils/statistics.md).

## Files

| File | Purpose |
|---|---|
| [SeatCard.md](SeatCard.md) | One seat's win-rate bar, placement pie chart, and score stats |
| [PlacementLegend.md](PlacementLegend.md) | Legend rows for `SeatCard`'s pie chart |
| [StatRow.md](StatRow.md) | Generic label/value row with an optional color swatch |
| [TeamPerformanceTable.md](TeamPerformanceTable.md) | Table of teams' actual vs. expected placement |
