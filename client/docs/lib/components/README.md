# `lib/components`

[← lib](../README.md)

All reusable UI components, grouped by feature area. [`ui/`](ui/README.md)
is the only feature-agnostic group; every other folder is specific to one
part of the app.

## Folders

| Folder | Purpose |
|---|---|
| [admin/](admin/README.md) | Admin dashboard tabs (results delegated to `results/`, plus rankings, statistics, import, feature flags, tournament settings) |
| [game/](game/README.md) | The current player's table-seating widget |
| [home/](home/README.md) | The participant start page: hero, running match, own score |
| [onboarding/](onboarding/README.md) | Team/player picker, welcome screen, seat/color setup |
| [results/](results/README.md) | Result entry, review, and signatures |
| [rules/](rules/README.md) | Per-game rule list + edit modal |
| [schedule/](schedule/README.md) | Tournament schedule timeline + edit modals |
| [shell/](shell/README.md) | App-wide navigation drawer |
| [statistics/](statistics/README.md) | Statistics tab's presentational pieces |
| [timer/](timer/README.md) | Interactive timer screen's UI |
| [ui/](ui/README.md) | Generic, app-agnostic UI primitives |
